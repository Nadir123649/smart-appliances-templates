✍️ 2. Easy Content Editing Guide (No Coding Required)

1

Editing Headlines & Subheadings

Headlines are enclosed inside <h1>, <h2>, or <h3> tags. Simply replace the text between the tags:

<!-- Example Headline in index.html -->
<h1 style="margin: 0; font-family: 'Afacad', sans-serif; font-size: 26px; color: #123A64;">
  How is your [appliance] doing, [first_name]?
</h1>
2

Editing Body Paragraphs

Paragraph text is enclosed inside <p> tags. You can modify any sentence directly:

<!-- Example Body Copy in template-3-review-request.html -->
<p style="margin: 0 0 14px 0; font-family: 'Manrope', sans-serif; font-size: 14px; color: #3A4B5B;">
  Need your refrigerator, washer, dryer, or oven repaired fast? Our certified local technicians are in <strong>[City]</strong> today.
</p>
3

Updating CTA Button Text & Booking Links

To change a button's destination URL, change href="...". To change the button text, edit the text inside the <a> tag:

<!-- Example Button Link -->
<a href="https://smartapplianceservices.com/booking" target="_blank" style="...">
  SCHEDULE YOUR REPAIR &rarr;
</a>
4

Updating Phone Numbers & Click-to-Call Links

Search for tel:7272757555 across any file. Update both the link and the visible phone string:

<!-- Example Click-to-Call Link -->
Prefer to call? <a href="tel:7272757555" style="..."> (727) 275-7555 </a>
5

Modifying Promo Codes & Discount Offers

Prices and codes are pure text. Search for the codes directly in your editor:

  • Template 2 ($89 Credit): Search for $89 or CLAIM YOUR SAVINGS.
  • Template 3 ($25 OFF / FAST25): Search for FAST25 or $25 OFF.
  • Template 4 ($30 OFF / CARE30): Search for CARE30 or $30 OFF.
<!-- Example Promo Code Text in Template 3 -->
Mention code <strong style="color: #123A64;">FAST25</strong> when booking online or by phone.
6

Swapping Placeholder Images with Real Photos

All logos and icons are hosted on Cloudinary CDN. When ready to replace placeholder graphics with real business photos (technicians, vans, repair scenes):

<!-- Replace the src="..." link with your photo URL -->
<img src="https://your-domain.com/your-technician-photo.jpg" width="140" alt="Technician" style="..." />

🔄 3. Dynamic Personalization Placeholders

The templates use standard brackets [...] for personalization placeholders. Replace these with your ESP merge tags when launching campaigns:

Placeholder Description Mailchimp Merge Tag Klaviyo Merge Tag
[first_name] Customer's first name *|FNAME|* {{ first_name|default:'there' }}
[appliance] Serviced appliance name *|APPLIANCE|* {{ event.Appliance|default:'appliance' }}
[City] / [city] Customer's local city *|CITY|* {{ person.city|default:'your area' }}
[City/Month] Location & service month *|CITY_MONTH|* {{ event.CityMonth }}

📥 4. ESP / CRM Deployment Instructions

⚡ 3-Step ESP Upload Guide
  1. Open the target template file (e.g. index.html) in any text editor and copy all the code.
  2. In Mailchimp, Klaviyo, HubSpot, or SendGrid, create a new email draft and select Code Your Own / Custom HTML.
  3. Paste the HTML code and save. You can now preview and send!
